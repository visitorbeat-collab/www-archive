# 2.0 Function

The reconstruction tests whether relationships described across several
recovered fragments remain intelligible when displayed simultaneously.

It is useful for examining:

- bounded and overlapping clusters
- direct and indirect dependency
- reciprocal and conditional connection
- redundant pathways
- peripheral structures with wider consequence

The diagram does not reproduce a recovered image. Node count, placement,
cluster arrangement, and visible pathways are explicit Finder decisions.

---

# 3.0 Public Voice

The public page is written in the Finder's first person. It states

---

# 4.0 Interpretation Constraint

The diagram demonstrates a possible organization of relationships. It
does not establish the original appearance, subject, physical scale, or
authority of the recovered material.

Visual clarity must not be mistaken for source confidence.

---

# Final Design Principle

A reconstruction may clarify the Finder's reasoning without becoming a
source artifact.
