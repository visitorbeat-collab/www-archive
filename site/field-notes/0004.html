0004 / FIELD NOTE

Classification

created: various revised: various status: retained

I originally organized these notes by subject because that seemed like the obvious thing to do.

Environment. History. Witness testimony. Scientific literature. Personal observations.

For a while it worked well enough.

Then the useful connections started appearing across the categories instead of inside them.

A piece of testimony would make more sense beside an environmental observation than beside other testimony. A technical paper would clarify something I had filed as a personal note. Material I had separated because it looked unrelated kept turning out to depend on the same underlying relationship.

Eventually I realized I was spending more time working around the classification system than using it.

So I changed the question.

Instead of asking what a document was about, I started asking what it was doing in relation to everything around it.

That sounds like a minor distinction, but it changed the Index more than I expected.

The structure became harder to explain to someone seeing it for the first time, and probably less elegant too.

But it became much more useful to me.

I still don't know whether that says something about the material or just about the way I think.
